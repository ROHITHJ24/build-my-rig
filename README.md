# 🧠 Build My Rig 🚀  
> A futuristic PC builder web app that lets users design and customize their dream rig with real-time compatibility validation and a stunning lab-themed UI.



---

## 🎯 What It Does  

Build My Rig simplifies the complex process of assembling a custom PC.  
It allows users to **choose compatible parts**, visualize their build in a **game-inventory-like interface**, and get **instant feedback on component compatibility**.  

Designed for **gamers, tech enthusiasts, and PC builders** who want to experiment and plan before they buy.

## ⚙️ Features  

✅ Dark & Light Mode toggle (default: dark)  
✅ Real-time component compatibility checks  
✅ Game-style UI inspired by The Witcher 3 inventory system  
✅ Interactive part selection with animations  
✅ Fully responsive across all devices  
✅ LocalStorage persistence for build data  
✅ Clean and modern Tailwind CSS-based design

## 🚀 How to Run Locally  

### Prerequisites  
- Node.js (v16 or higher)  
- Git  

### Installation  
```bash
# Clone the repository
git clone https://github.com/ROHITHJ24/build-my-rig.git

# Navigate into the folder
cd build-my-rig

# (Optional) If using Node modules later:
npm install

# Open the index.html file directly in your browser
